# Working agreements

## Writing style

**Never use em dashes (—) or en dashes (–).** This applies everywhere, without
exception: chat replies, drafted emails, memos, documents, code comments, commit
messages, file contents, and anything sent to another person on my behalf.

Use one of these instead:

| Instead of an em dash | Use |
|---|---|
| Joining two related clauses | A comma, or split into two sentences |
| Setting off an aside | Commas, or parentheses |
| A range (3—5 days) | A hyphen: 3-5 days |
| Before a definition or list | A colon |
| A label before an explanation | A colon, or a hyphen |
| An abrupt break or emphasis | A period, or a comma |

A hyphen (-) is fine. It is the only dash character I want to see.

This is not a preference to weigh against readability. If a sentence seems to
need an em dash, rewrite the sentence.
